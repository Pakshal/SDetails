A current directory.

Update locations and our shared Suvichar through GitHub. Sign in with the GitHub account invited by the directory owner.

Editing links become available after this site is deployed from its GitHub repository.

Update locations

Open the location file on GitHub. Each entry has a name and an address. Edit an existing entry, add a new one, or remove an entry.

[
  {
    "name": "Enter Sadhviji name",
    "address": "Enter current address"
  }
]

Keep double quotes around each value. Separate entries with a comma; leave no comma after the last entry. For a line break inside an address, use \n.

Edit names & addresses on GitHub ↗

Share a Suvichar

Open the Suvichar file and replace its text with your message. English, Hindi, and Gujarati are supported. No quotes or formatting are needed. Leave it empty to hide the section.

Edit Suvichar on GitHub ↗

Save and publish

  1. On GitHub, choose Commit changes….
  2. Write a short description and choose Commit directly to the main branch, then confirm. If the repository requires review, create a pull request and ask the owner to merge it.
  3. GitHub checks the files and publishes the site automatically. This usually takes a few minutes.
  4. Return to the directory and refresh to check your update.

If a check fails, the current website stays live. Open the deployment status, read the error, and fix the data file. If GitHub says the file changed while you were editing, reload the latest version and reapply your changes.

View deployment status on GitHub ↗
